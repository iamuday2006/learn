# SQL vs NoSQL Cheat Sheet

**SQL**: Relational, fixed schema, ACID, joins, vertical (mostly), strong consistency. (PG/MySQL)

**NoSQL**: Flexible, distributed, horizontal, BASE/eventual (tunable). Types: KV(Redis), Doc(Mongo), Wide-col(Cassandra), Graph(Neo4j)

**When**: SQL correctness/joins. NoSQL scale/flex/semi-structured.

**ACID vs BASE**: ACID strong. BASE BA,Soft,Eventually Consistent.
