# Data Engineering Fundamentals

This knowledge base turns the book Fundamentals of Data Engineering into a practical, interview-ready mental model for data engineering work.

## What this knowledge base covers
- Core concepts behind building data pipelines and platforms
- How data moves from source to analytics
- Storage, ingestion, modeling, processing, orchestration, reliability, and cost
- Data quality, governance, security, and metadata
- Cloud and modern data stack patterns
- System design and interview reasoning

## How to study it
1. Read the concept file in order.
2. Focus on the problem each concept solves.
3. Learn the trade-offs, not just definitions.
4. Connect the idea to a real pipeline: Source -> Ingestion -> Storage -> Processing -> Serving
5. Use the interview questions for review.

## Prerequisites
- Basic SQL
- Basic Python or scripting
- Understanding of tables, files, and APIs
- Familiarity with cloud concepts is helpful but not required

## Beginner -> Intermediate -> Advanced
### Beginner
- Data lifecycle
- Sources and ingestion
- Storage choices
- Warehouse and modeling basics
- Batch vs streaming

### Intermediate
- CDC, idempotency, partitioning, quality checks
- Orchestration and dependencies
- Metadata, lineage, and governance
- Reliability and performance tuning

### Advanced
- Designing large-scale systems
- Streaming semantics and late data handling
- Cost-aware architecture
- Data contracts and production observability

## Interview preparation strategy
- Learn the pattern: concept -> problem -> solution -> trade-off
- Practice explaining with examples
- Prefer business examples over pure theory
- Be ready to answer: What is it? Why use it? When choose it? What are trade-offs?
- Explain system design using architecture layers rather than random tools
