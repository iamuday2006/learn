# 14 — Data Security

Data engineering is not only about moving data; it is also about protecting it.

## Core concepts
- Authentication: proving identity
- Authorization: granting access
- IAM: identity and access management
- Roles and permissions
- Encryption at rest
- Encryption in transit
- Secrets and credential management
- Network security
- Least privilege
- PII protection

## Practical view
A data engineer must ensure:
- only trusted services access data
- credentials are stored securely
- sensitive data is encrypted
- access is restricted to the minimum required

## Must Know
- IAM and least privilege
- Encryption at rest and in transit
- Secrets management
- PII protection

## Good to Know
- Network controls
- Key rotation

## Advanced
- Zero-trust architecture
- Managed key systems

## Interview Questions
1. What is the difference between authentication and authorization?
2. Why is least privilege important in data systems?
3. Why encrypt data both in transit and at rest?
4. What is the risk of storing secrets in code?
5. How would you protect PII in a pipeline?
