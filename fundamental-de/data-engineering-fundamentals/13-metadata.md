# 13 — Metadata

Metadata is data about data.

## Types
- Technical metadata: schemas, types, file names, pipeline names
- Business metadata: field meanings and definitions
- Operational metadata: job runs, errors, SLA details
- Schema metadata: column definitions and constraints

## Data lineage
Lineage answers: where did this data come from and what changed it?

## Catalogs
A catalog stores metadata so users can discover, understand, and trust datasets.

## Questions metadata should answer
- Where did this table come from?
- Who owns it?
- What does this column mean?
- Which pipeline produced it?
- Which dashboards depend on it?
